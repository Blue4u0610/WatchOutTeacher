# WatchOutTeacher v0.2.3

## 中文

单文件上限提升至 100 MB；批量导入显示收到数量、逐项进度和失败原因，处理中可继续追加文件。

- 系统：Windows / macOS。首次正式发布当前版本，并补齐 GitHub 版本历史与自动发布流程。
- 下载下方 **WatchOutTeacher-v0.2.3.zip**，包含扩展、本地桥接及安装脚本；不是双击即装的程序，也不包含 Python 或 AI CLI。
- 解压后按系统指南安装：[macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.2.3/docs/INSTALL.macos.md) · [Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.2.3/docs/INSTALL.windows.md)。浏览器加载解压目录中的 **extension** 子文件夹。
- **SHA256SUMS.txt** 用于核对下载完整性。旧版本只供回溯，日常使用建议下载 [最新版本](https://github.com/Blue4u0610/WatchOutTeacher/releases/latest)。

## English

Raises the file limit to 100 MB. The import queue shows received counts, individual progress and errors, and accepts additional files while processing.

- Platforms: Windows / macOS. First formal release of the current version, with version history and an automated release workflow.
- Download **WatchOutTeacher-v0.2.3.zip** below. It includes the extension, local bridge and install scripts; it is a source bundle, not a standalone installer. Python and AI CLIs are separate prerequisites.
- Extract and follow the setup guide: [macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.2.3/docs/INSTALL.macos.en.md) · [Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.2.3/docs/INSTALL.windows.en.md). Load the extracted **extension** subfolder in your browser.
- **SHA256SUMS.txt** verifies download integrity. Older versions are retained for reference; use the [latest release](https://github.com/Blue4u0610/WatchOutTeacher/releases/latest) for everyday use.

## 验证与限制 / Validation and limits

Windows 与 macOS 自动检查通过：40 项 Python 测试（macOS 跳过 2 项 Windows 专用测试）、44 项浏览器检查，以及安装／重装／卸载检查。浏览器测试使用模拟回答服务，不等于真实 AI 账户测试。

Both OS suites cover 40 Python tests (two Windows-specific tests are skipped on macOS), 44 browser checks and installer lifecycle checks. Browser checks use a mock answer provider, not live AI credentials.

Zotero 跨应用拖放仍需核对浏览器收到的文件数；PPTX 图片、图表含义和备注不参与文本索引。See the tagged [testing scope](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.2.3/docs/TESTING.md) for remaining limitations.
