# WatchOutTeacher v0.3.0

## 中文

Gemini 现在可以回答划选题目，并参考已有课程资料与回答要求。接入使用 Google 的 **Antigravity CLI 1.4.2**，模型下拉框直接读取当前账户；可用时，High / Medium / Low 随模型选择。备用服务改为勾选列表，升级不会自动启用 Gemini。

- 安装：[Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.windows.md) · [macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.macos.md)。无需 Node.js。
- 运行 `agy` 完成 Google 登录及首次设置，然后在插件中刷新模型列表、选择 Gemini 并保存。旧版 `gemini` 命令不再使用。
- 更新后重新运行安装脚本并在扩展管理页重新加载，原有课程资料会保留。
- Gemini 使用 Google 账户额度，CLI 保留本地会话记录。当前适配器会拒绝全局 Hooks、MCP、插件、规则或尚未验证的 CLI 版本。

## English

Gemini now answers selected questions using the same course retrieval and saved answer instructions. The integration uses Google's **Antigravity CLI 1.4.2**, with models read from the signed-in account. High / Medium / Low variants appear in the model choice when available. A fallback checklist lets you choose which accounts may be used; upgrades do not opt into Gemini.

- Setup: [Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.windows.en.md) · [macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.macos.en.md). No Node.js required.
- Run `agy`, complete Google sign-in and onboarding, then refresh models, select Gemini and save in the extension. The legacy `gemini` command is not used.
- After updating, rerun the bridge installer and reload the extension. Existing course data is preserved.
- Gemini uses the Google account's allowance and the CLI retains local conversation records. Global hooks, MCP, plugins, rules and unverified CLI versions are rejected by this adapter.

## Validation / 验证

Release checks: 47 Python tests, 45 browser checks per platform, installer lifecycle and native CLI version/flag checks on Windows and macOS. CI has no AI credentials. Separate macOS live tests passed arithmetic, course retrieval with a citation, and a file-access canary. Windows real-account inference remains unverified.

发布检查包括双平台自动测试；macOS 额外完成真实 Gemini 回答、资料引用和文件访问隔离试验。Windows 的真实账户调用仍需本地验证。没有新增 OCR。
