# WatchOutTeacher v0.3.0

## 中文

加入 Gemini CLI：在插件设置中选择 Gemini，沿用已有课件、引用和回答要求。自动、Pro、Flash、Flash-Lite 可直接下拉选择，也保留自定义模型 ID。备用服务改为勾选列表；升级不会自动启用 Gemini 或切换首选账户。

- Windows / macOS 共用 **WatchOutTeacher-v0.3.0.zip**；使用 **SHA256SUMS.txt** 核对完整性。
- 安装：[Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.windows.md) · [macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.macos.md)。需要 Node.js 和 Gemini CLI，已验证 CLI 版本为 0.64.0。
- 运行 `gemini`，选择 **Login with Google**。目前只支持 Google OAuth；不使用 API Key / Vertex AI，不与 Codex 共用额度。
- 更新后重新运行桥接安装器，再重新加载浏览器扩展和题目页。现有课程索引保留。

## English

Adds Gemini CLI as a provider, sharing existing course retrieval, references and answer instructions. Choose Auto, Pro, Flash, Flash-Lite or a custom model ID. Select which fallback providers may run; upgrading does not enable Gemini or change the preferred account automatically.

- Download **WatchOutTeacher-v0.3.0.zip** for Windows or macOS; verify it with **SHA256SUMS.txt**.
- Setup: [Windows](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.windows.en.md) · [macOS](https://github.com/Blue4u0610/WatchOutTeacher/blob/v0.3.0/docs/INSTALL.macos.en.md). Node.js and Gemini CLI are required; the tested CLI version is 0.64.0.
- Run `gemini` and choose **Login with Google**. This adapter supports Google OAuth only, without API keys or Vertex AI. Gemini uses its own account quota.
- Rerun the bridge installer, reload the extension and refresh question pages. Existing course data remains in place.

## 验证与限制 / Validation and limits

发布检查包括 47 项 Python 测试（macOS 跳过 2 项 Windows 专用测试）、45 项浏览器检查、安装器生命周期和真实 Gemini CLI 的离线配置／策略验证。CI 不持有 AI 凭据；本次未完成真实 Gemini 账户回答验证，需本人登录后试题。模型预设不等于账户权限，不新增 OCR 或 Gemini 推理强度档位。

Release checks include 47 Python tests (two Windows-only checks are skipped on macOS), 45 browser checks, installer lifecycle and offline configuration/policy validation against the real Gemini CLI. CI has no AI credentials. Live Gemini answers have not been verified in this release; sign in and try a small question. Presets do not imply model entitlement. OCR and a separate Gemini effort control are not included.

Gemini 会话缓存会在正常结束后清理；崩溃或 CLI 存储变化可能留下记录，项目路径登记会保留。Gemini session caches are cleaned after normal completion; crashes or CLI storage changes may leave records, and project-path metadata remains.
