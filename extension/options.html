课程 AI 助手

WatchOutTeacher

按住 Alt / Option 拖选题目，在原处读答案。

只在你主动划词时发送题目及相关资料片段，经本机 CLI 交给对应 AI 服务处理。课程索引保存在本机。工具不会点击答案或提交作业；模型使用受对应账户额度与条款约束。

正在连接本地桥接…

1 · 网站授权

可以逐个授权网站，也可以一次授权所有 HTTP / HTTPS 网站。全部授权后，其他域名的题目 iframe 也能使用。授权后刷新题目页。

    支持 HTTP / HTTPS 网页；Chrome 内部页面、扩展商店等受浏览器保护的页面不支持。全部授权后仍仅在你按住快捷键拖选时发起提问。

    2 · 当前课程

    删除课程会移除该课程的本地资料索引，原始文件不受影响。

    课程资料

    PDF、TXT、Markdown、PPTX，每个文件最多 100 MB。PDF 使用文件页码；扫描件需先 OCR。

      3 · 模型和操作

      优先参考资料、改写表达、依据不足时说明。可自定义语言、长度和资料使用方式，最多 2,000 字；适用于所有课程及首选／备用服务，保存后对下一题生效。留空使用默认要求。

      每题独立会话；关闭、切题或取消不会触发备用。选择自动时使用 CLI 默认模型，不继承用户的自定义 CLI 模型配置。模型选择仅影响本插件，保存后对下一题生效。强度越高通常等待越久、消耗越多。强度设置仅用于 Codex，备用 Claude 使用自身默认。Ultra 涉及自动任务分派，本插件不提供此档位。Claude Code 未安装不影响 Codex。

      4 · 连接与诊断

      诊断仅保留最近 100 次的 Provider、请求的模型与强度、错误类别、用时和检索数量，不保存题目与答案正文。检测安装与登录状态不等于模型调用成功。
